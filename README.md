# Energy Core Commerce

Build a modern, premium e-commerce website for a company that sells lithium batteries and related energy products, including battery packs, LiFePO4 batteries, BMS systems, chargers, power stations, accessories, and other related products.

The website should feel like a professional, trustworthy, high-end technology/energy brand, with an exceptional UI/UX experience. It should be fully responsive and look polished on desktop, tablet, and mobile.

Create a complete e-commerce experience including:
Beautiful homepage with a strong hero section
Product categories
Product listing/shop pages
Product search and filtering
Product detail pages
Product images and technical specifications
Shopping cart
Checkout
Customer sign up/sign in
Customer accounts
Order history and order tracking
Wishlist
Product reviews
Contact and informational pages
Responsive navigation and footer

Also build a complete admin dashboard where administrators can manage the entire store, including:
Products
Product images
Categories
Inventory/stock
Orders
Customers
Payments
Discounts/coupons
Reviews
Homepage content
Other important store settings

Admins should be able to easily add, edit, remove, publish, and manage products from the dashboard. Adding a product should support things relevant to batteries, such as price, stock, SKU, voltage, capacity, chemistry, dimensions, weight, warranty, specifications, images, and other product information.

Use Supabase as the backend for authentication, database, storage, products, users, orders, inventory, and other application data.

VERY IMPORTANT
Do NOT enable or use Lovable Cloud.

I already have my own Supabase project and will connect it to the application. The application should be designed to work with my existing Supabase infrastructure rather than creating a Lovable Cloud backend.

For now, focus on building the overall product, UI/UX, architecture, storefront, customer experience, and admin experience. Make sensible technical decisions yourself and use best practices.

The design should be modern, elegant, clean, premium, and conversion-focused. Avoid making it look like a generic template or basic CRUD application.

Use realistic placeholder content/products where necessary so the website feels complete during development. We can provide more detailed requirements and customize individual features in later prompts.

Build this as a real production-quality e-commerce application, not just a visual prototype.
